# Release boundary and future work

The [current core evidence](CORE_RESULTS.md) separates completed engineering and measurements from unmeasured claims. The quoted-draft reader, bounded concurrency, real UI demonstration, frozen single-call/ReAct control and 180-case quote-policy robustness profile are implemented and published. High format failure remains part of the original robustness result; a complete-schema prompt correction has a separate bounded confirmation condition.

The opt-in PostgreSQL profile already provides persistent incremental vectors, two-process coordination, tenant authorization, shared quotas and renewable ingestion leases. Real CI checks tenant denials, worker recovery and backup/fresh-database restore. These are single-host evidence, not multi-host storage, regional failover or a hosted-reader SLA.

The bounded own-document study still requires the private human confirmation and actual-answer review. Synthetic source proposals, exact span locations and automatic checks never become human labels by themselves. A running public service also requires an operator-controlled free hosting target and private runtime configuration; publishing source or a container does not establish availability.

Future research includes larger independently labeled PDF attribution, claim-extraction recall, context-grouped selective calibration and review-cost comparisons. No useful calibrated automatic coverage or review-time savings has been demonstrated. Hindi end-to-end attribution and a balanced English/Hindi local-reader cohort remain unmeasured; French stays gated until measured. Adaptive retrieval benefits remain unmeasured because both frozen-control arms made one call per question.

Further production work includes multi-host object storage, regional recovery, external availability monitoring, retention schedules and representative hosted-service load. Those are outside the bounded release and have no completed production claim. Keep all further work inside available free resources and explicit compute caps; no paid fallback is authorized.
