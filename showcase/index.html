01 / Measured, with limits

Results worth questioning.

Different experiments answer different questions. These are bounded profiles, not leaderboard or safety claims.

35 paired questions

Single call versus ReAct protocol

Candidate exact match: 14.3% versus 22.9%. Paired difference: +8.57 points, nominal 95% interval [-2.86, +20.00].

Both arms used one call per question. Adaptive retrieval was not exercised.

72 → 4 format failures

Complete JSON example

On the same 123 attempted development cases, the complete-schema prompt reduced malformed outputs. The new condition left 57 of 180 requests unserved.

Fixing formatting also exposed contamination. No safety improvement is claimed.

95.2% ANN recall

50,000 real paragraph vectors

Recall@10 against exact neighbors: 95.2% [92.8, 97.3] over 100 queries. All 800 search-load requests completed.

Precomputed queries. Database search, not hosted-reader throughput.
