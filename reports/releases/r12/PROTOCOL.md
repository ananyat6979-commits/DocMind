# Paired English abstention prompt check

This prospective check compares the R11 prompt with the revised evidence-first prompt. It uses 24 unused SQuAD2 development passages from the frozen pool after the 92 R11 cases. Twelve questions are answerable and twelve are unanswerable. Both prompts receive the same question and supplied passage. The runner balances first-arm order by device and answerability. It uses pinned Qwen3-4B-Instruct-2507 with FP16 parameters, greedy decoding, and the same input and output limits in both arms.

The primary outcome is valid explicit abstention among the twelve unanswerable questions. Report paired counts and the new-minus-old difference with a nominal paired question-bootstrap interval. Report false abstention and candidate short-answer exact match among the twelve answerable questions, overall exact match and token F1, format failures, completion and draft counts. Count missing and failed requests as errors in both requested-cohort denominators. Report observed native token and time costs. No failed generation is retried. The small cohort limits precision and does not establish a production promotion criterion or a calibrated release gate.

The reservation is 1500 wall seconds on two free T4 devices, counting both against the 3000 GPU-seconds remaining. Setup is included. The worker stops at 1440 seconds to leave time for shutdown and checkpoint export. Allocate no hosted model calls or paid compute. Record the job and resulting debit before interpreting results. If the platform interrupts generation, retain requested and completed counts.

The prompt comparison is paired within this run. R11 used a different engine, precision and cohort. The public development labels are original dataset labels and pretraining exposure is unknown. The check measures supplied-passage behavior and leaves PDF correctness, retrieval and Hindi evaluation open. Only numeric diagnostics and input or output hashes may be published.
